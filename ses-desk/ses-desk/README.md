# SES//BUILDS desk prototype

A working prototype of the new portfolio home page.

- `index.html` is the whole page: HTML, CSS and JavaScript in one file. Open it in a browser to try it. Content for each drawer page lives in the `<template>` blocks near the bottom of the file.
- `scene.webp` is the painted desk (1672x867). The top navigation strip of the original image has been cropped off, because the page draws its own header.
- `ANTIGRAVITY_PROMPT.md` is the prompt for porting this into the real site.

Placeholders to replace: the four draft blog titles, the empty photo frames, and the boarding pass text.
